# Localize ad copy

Adapt English copy for FR, ZH, and AR using OpenRouter with cultural context.

## Command

```bash
npm run localize
npm run localize -- --auto   # skip approval prompt
```

## Prerequisites

- `npm run copy` completed

## Outputs

- Updated `copy_by_locale` in `outputs/.state/pipeline-state.json`

## Approval gate

Terminal shows sample headlines per locale. Press Enter to continue unless `--auto`.
